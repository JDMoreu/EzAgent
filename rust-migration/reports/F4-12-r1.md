## Decisiones
- **Driver por llamada**: el Python hereda `AgentDriver` dentro de `Herdr`; en Rust `Herdr` no implementa `LaunchSupport` (`ez-herdr` no depende de `ez-agent`). `delegate.rs` construye `AgentDriver::new(Arc::clone(herdr), herdr.config())` en cada `run`/`agents`/`configure`, como recomienda el informe de F4-11 para no quedarse con una configuración vieja.
- **`DelegateError` tipado**: las ramas `_ArgumentError` y `HerdrError` se portan literalmente. La rama genérica `except Exception` → `Error inesperado al usar Herdr: {tipo}: {mensaje}` es inalcanzable en Rust (no hay excepciones arbitrarias) y se omite; un pánico de un callback lo captura el registro con su propio texto. Marcado `DECISION`.
- **`HerdrCallbacks`**: el `dataclass` con callbacks obligatorios y opcionales se convierte en un struct con `Arc<dyn Fn … + Send + Sync>`, `async_launch: bool` y `Default` con callbacks nulos, para poder construir la herramienta con `..Default::default()`.
- **`with_labels` en el manejador**: Python envuelve `_handle_delegate`/`_handle_voice` con `partial(_with_labels, herdr, …)`; aquí el cierre del `ToolSpec` aplica `with_labels` al `ToolResult`, incluida la rama de error (sin efecto).
- **`describe_fn`**: el resolutor de nombres es un cierre sobre `Arc<Herdr>` que llama a `label_for`; si no hay caché, `_shown` cae a «el agente indicado», igual que `label_for=None/*` en el Python.
- **`then` inválido**: `parse_steps` devuelve `String`; se convierte a `ArgumentError` para que el texto final sea el mismo (`El parámetro «then»…`).
- **Enteros fuera de `i64`**: `optional_lines`/`mute` tratan un entero JSON mayor que `i64` como fuera de rango (no como tipo inválido) para llegar al mismo mensaje que Python; los resúmenes imprimen dígitos con `python_str`.
- **`keys`**: `Herdr::keys_agent` recibe `&[String]`, así que cada elemento se convierte con `python_str` antes de `valid_keys` (el Python hace `str(k)` dentro de `valid_keys`).
- **Límites de lectura**: `read` pasa `6000` como `limit` y `_read_output` pasa `1500` líneas a `read_full` (los valores por defecto del Python de F4-10).
- **Shell**: `open_terminal` usa `DEFAULT_SHELL` de `ez-herdr` («powershell.exe»), el mismo literal del Python.
- **Submódulos**: `args/parameters.rs` y los cinco `*/tests.rs` existen para respetar el tope de 600 líneas; no se tocó ningún archivo fuera de `tools_herdr/`.
