## Decisiones
- `// DECISION` `store.rs` guarda JSONL (`chat.jsonl`) y no SQLite: el Python de `voice/chat/store.py` y `tests/test_chat_store.py` usan JSONL; `history.db` es de `agent/memory.py` (F3-09). Manda el Python y no se toca `Cargo.toml`.
- `// DECISION` `load_image` valida tipo, permisos, tamaño y píxeles desde la cabecera y devuelve `LoadedImage` con ruta y dimensiones. Convertir a RGBA exige el crate `image`, que `ez-chat` no declara y el brief prohíbe añadir; la decodificación queda para el HUD (F5-13), que sí puede declararlo.
- `// DECISION` `open_file` abre con `explorer` (argumento en lista, sin shell) porque `os.startfile` no existe en `std`; `reveal_file` usa `explorer /select,<ruta>` como el Python.
- `// DECISION` `TextInput::move` se llama `move_cursor` porque `move` es palabra reservada.
- `// DECISION` `stamp` devuelve `""` y avisa por `tracing` con instantes fuera de rango; el Python lanzaría `OSError` en Windows.
- `// DECISION` `spoken_version(markdown, max_chars)` porta la firma del fixture y `spoken(markdown)` aplica el tope por defecto de Python.
- `// DECISION` `ChatModel::snapshot` devuelve `Vec<ChatMessage>` en vez de una tupla Python; el contenido y la versión son los mismos.
- `shortcut:` el sniffing de CSV elige el delimitador más consistente entre `, ; \t |`; no reproduce todos los modos de `csv.Sniffer`, solo los CSV/TSV reales del chat.

## Pendiente o riesgos
- `media.load_image` no entrega píxeles RGBA (ver Decisión); el resto de la política de visualización sí está portado y probado.
- `open_file` delega en el Explorador: si no hay aplicación asociada, `explorer` puede devolver éxito igualmente; el Python distinguiría con `OSError`.
- `csv.Sniffer` está simplificado (`shortcut:`); datos con delimitadores mezclados o comillas atípicas pueden elegir otro delimitador que el Python.
- Rareza del Python reproducida: `ChatStore.recent(0)` devuelve **todo** el historial porque `-max(0, 0) == 0`. No se corrige.
- No se editó `rust-migration/python-quirks.md` porque el brief solo permite archivos de `ez-chat`; la rareza de `recent(0)` queda anotada aquí.
