## Pendiente o riesgos
- **Kokoro es una dependencia de regeneración**: los WAV de voz solo se reproducen byte a byte con `kokoro-v1.0.int8.onnx` y `voices-v1.0.bin` instalados. Sin ellos el generador usa una voz armónica determinista y cambia los sha256; el fallback está implementado y documentado, pero el manifiesto solo coincide con la corrida que use Kokoro.
- **Smart Turn**: los 27 casos de probabilidad requieren `smart-turn-v3.2-cpu.onnx`. Sin el modelo, `turn.jsonl` se genera solo con las 60 funciones de características (el `generate` omite las probabilidades), así que el hash del fixture cambia. La inferencia ONNX aún no está cableada en Rust (F4-04).
- **Diferencias conocidas del Python que los fixtures exponen** (no se corrigieron, son el oráculo):
  - `wave` escribe un byte de relleno cuando el PCM tiene longitud impar: un PCM de 3 bytes produce un WAV de 49 bytes. El `pcm_to_wav` de Rust actual no rellena, así que la prueba de paridad lo marcará.
  - `Segmenter` aprende como suelo de ruido un tono constante que empieza en el primer chunk: `tone_440_1s` y `synthetic_voiced_3s` nunca arrancan habla. Es el comportamiento real de la calibración inicial, no un fallo del generador.
  - `prepare` con un byte impar lanza `ValueError: buffer size must be a multiple of element size`; el port de `ez-audio` descarta el byte por decisión propia.
  - `prepare` con tasa 0 lanza `ZeroDivisionError: division by zero`; con tasa negativa devuelve una ventana de una muestra en vez de fallar.
  - `resample_length` con tasa de origen 0 lanza `ZeroDivisionError: division by zero` (división entera), no «float division by zero».
- Los casos `fn: "wav"` son metadatos de los WAV, no llamadas a una función Python; el consumidor de paridad debe saltarlos al despachar por `fn`.
- `pcm_is_weak` incluye una tasa negativa que el Rust no puede representar con `u32`; la prueba de paridad puede omitirla o adaptarla.
- No se ejecutó `run_all.py` (habría reescrito `parity/gen/manifest.json`, prohibido en este brief). El orquestador debe regenerar el manifiesto al integrar.
