## Decisiones
- **Solo `docs-staging` y F7-06**: no se tocaron `README.md`,
  `docs/architecture.md`, `AGENTS.md` ni `docs/llm-providers.md`; la copia se
  hace después de la auditoría, como pide el brief.
- **whisper se documenta como requisito de instalación**: la app Rust descarga
  Kokoro y Smart Turn por su cuenta, pero no tiene un subcomando de descargas
  equivalente a `python -m ezagent.core.downloads`. El README lo dice tal cual:
  se instala una vez con el descargador del repositorio o se copia a
  `%LOCALAPPDATA%\EzAgent\whisper`. No se inventó una descarga que el código no
  hace.
- **README con la interfaz real de Rust**: cinco secciones de Ajustes (Aspecto,
  Escucha, Voz, Modelos, Sistema), cuatro botones de barra (☰, 💬, 🎤, ✕), seis
  atajos (incluido `Ctrl+Alt+T`) y el chat escrito. La tabla de configuración
  del README antiguo se sustituyó por la descripción de los controles reales.
- **Modo autónomo documentado con el diseño v2**: criterios con `text`/`check`,
  confirmación única, aprobación de una sola vez, dos verificaciones limpias,
  topes 5/120/200, parada por voz/atajo/fila y artefactos en
  `%APPDATA%\EzAgent\autonomo\<id>\`.
- **Regla de cerrojos con la excepción conocida**: se escribe la regla
  (ningún lock durante operación larga, llamada a otro componente, ventana o
  disco) y se anota que `HudConfig::save` todavía escribe `voice.json` con el
  lock de configuración tomado; es un retardo, no un interbloqueo, y queda para
  la tarea de rendimiento.
- **F7-06 deja el diálogo de confianza del modo B como manual**: si un miembro
  se queda en «¿confías en esta carpeta?», la lista pide aprobarlo a mano y
  anotarlo, que es la limitación conocida del modo B.
- No hay `// DECISION` de código: no se modificó ningún `.rs`.

## Pendiente o riesgos
- **Instalación en un equipo nuevo**: el instalador no incluye whisper.cpp ni su
  modelo y el binario Rust no tiene un subcomando de descargas. Hoy hace falta
  el descargador de Python o copiar la carpeta `whisper` a mano. Conviene una
  tarea F8 posterior que añada `ezagent-voice downloads` (o que el instalador
  empaquete/descargue whisper); el README ya lo declara como requisito.
- **`barge_in_mode` no se persiste**: el valor por omisión de la app es
  `adaptive`, pero `ez-core` no tiene la clave en los valores de fábrica (riesgo
  ya anotado en P-IMP-BARGEIN). El README no pide al usuario que la edite; si
  alguien la escribe a mano, un guardado de Ajustes la puede descartar.
- **Referencia Python**: el README y AGENTS dicen «mientras el repositorio
  conserve la versión Python». Si la auditoría la elimina, hay que ajustar esas
  frases y la sección de pruebas (el resto del documento sigue siendo válido).
- **F7-06 no se ejecutó** (es una lista para el usuario): sus pasos no están
  probados en hardware real por esta tarea. El punto 9 incluye la limitación
  conocida del diálogo de confianza del modo B.
- No se ejecutó `cargo test --workspace` completo ni la reproducción de 25
  escenarios: no hay cambios de código y la suite de `ez-app` ya quedó verde;
  hacerlo habría ocupado varios minutos de CPU compartida con otros workers.
