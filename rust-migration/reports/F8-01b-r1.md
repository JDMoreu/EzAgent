## Pendiente o riesgos
- `EzAgent.bat install` no se ejecutó de punta a punta: `uv sync` de esta versión de uv reescribe `uv.lock` y los dos `cargo build --release` son los mismos que ya ejecuta `build-rust.ps1`. Los comandos quedan tal cual en el `.bat`.
- En modo Rust el `.bat` no mantiene abierta la consola si el ejecutable termina con error (el arranque Python usa `-NoExit`); el error queda en el log de la app. Envolverlo en PowerShell añadiría un proceso intermedio.
- Sin `.venv`, el ejecutable de desarrollo no encuentra `onnxruntime.dll` ni `espeak-ng` (el stage sí, porque los lleva al lado); el aviso del `.bat` lo explica.
- `--list-agents` devolvió una lista vacía en la comprobación final porque el agente de Herdr había terminado; la ejecución fue exit 0 y, con el agente activo, antes imprimió la fila `t51`.
