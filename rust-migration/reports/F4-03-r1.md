## Decisiones
- `// DECISION`: `client.rs` se parte en `client/models.rs` y las pruebas en `client/tests.rs` / `server/tests.rs` para respetar el límite de 600 líneas (máximo final 506).
- `// DECISION`: no se porta `atexit.register(close_client)`; en Rust el cliente se libera al terminar el proceso.
- `// DECISION`: no se porta el reemplazo de `httpx.post` (costura de las pruebas del Python); el parámetro `client` de `transcribe` cubre la inyección.
- `// DECISION`: si un JSON de respuesta no es objeto, se usa el cuerpo como texto en vez del `AttributeError` que lanzaría `response.json().get(...)`; nunca se pierde la frase.
- `// DECISION`: un `stt_timeout_secs` negativo o no finito no se pasa a `Duration` (entraría en pánico); negativo termina con el error de conexión y no finito vuelve a 60 s.
- `// DECISION`: `_resource_root` usa la ruta del crate en tiempo de compilación; no hay equivalente a `sys._MEIPASS` en Rust.
- `// DECISION`: el servidor se lanza con `powershell -File scripts\\start-whisper.ps1` y argumentos en lista, igual que el Python, con `env_clear` + copia explícita del entorno y `CREATE_NO_WINDOW`; nunca se usa `-Command` ni texto interpolado.
- `// DECISION`: `_free_local_port` devuelve `Option<u16>` (el `OSError` del Python no tiene equivalente útil aquí) y `ensure_whisper` conserva el `wait_secs=25.0` con `ensure_whisper`/`ensure_whisper_with`.
- No se añadieron entradas a `python-quirks.md`: no encontré un error del Python que reproducir; el caso del JSON no objeto queda documentado como decisión.

## Pendiente o riesgos
- El lanzamiento real de `whisper-server.exe` (PowerShell, Vulkan/CPU, modelos descargados) no se ejecutó en esta sesión: la construcción de argumentos, el sondeo TCP y todas las ramas que no arrancan están probadas; falta la validación manual con un `whisper_home` real.
- Los textos de error de `reqwest` no son idénticos a los de `httpx` (clase y mensaje); se conserva el prefijo y el formato del Python, y las pruebas de paridad deberán comparar por subcadena o normalizar.
- `_text` con un JSON que no sea objeto usa el cuerpo como texto (decisión), en vez del `AttributeError` no capturado del Python.
- `_whisper_ready` resuelve nombres con `ToSocketAddrs`; un host no local solo se probó con loopback, no contra DNS real.
