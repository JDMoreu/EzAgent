## Decisiones
- `// DECISION` el `_text_type` de `normalize_for_speech` no se lee nunca en el Python (se llama `_text_type` y el `text_type` de `normalize_for_kokoro` solo se reenvía), así que la API pública es `normalize_for_speech(text)` / `normalize_for_kokoro(text)`.
- `// DECISION` el trozo de `num2words` vive en `speech_text/numbers.rs`: con las tablas de textos y palabras el módulo pasaba de 600 líneas (límite duro de `gate.ps1`).
- `// DECISION` en `money_words`, una moneda desconocida devuelve el texto original; el Python lanzaría `KeyError` y el patrón solo deja pasar monedas de la tabla.
- `// DECISION` en `correct_transcription`, si el patrón no compila se devuelve `DictionaryError::Malformed`; solo puede pasar por un fallo del programa (todo el texto va escapado).
- `// DECISION` sin caché LRU para las reglas compiladas del diccionario (el Python usa `lru_cache(maxsize=32)`); la compilación por llamada entra en el presupuesto de una transcripción.
- `shortcut:` `casefold` del Python se sustituye por `to_lowercase()`; difiere en `ß`/ligaduras y solo afecta a la detección de duplicados.
- `shortcut:` `" ".join(x.split())` se porta con `split_whitespace`, que no separa en `\x1c`-`\x1f`; ningún fixture lo usa. Lo mismo para `str.strip()` en el diccionario.
- `shortcut:` los enteros de `num2words` son `i64`; el Python no tiene límite y solo cae a dígito a dígito por encima de 19 cifras.
