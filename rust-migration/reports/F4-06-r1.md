- `// DECISION`: `build_body` de OpenAI aplana `extra_body`, descarta claves privadas (`_…`) y `timeout`, y fuerza `stream=true`; el `timeout` se aplica al cliente HTTP.
- `// DECISION`: un evento `error` en mitad del flujo OpenAI se convierte en `LlmError` con el formato `Error code: …` del SDK (el SDK de Python no expone ahí un texto propio).
- `// DECISION`: un evento SSE que es JSON pero no objeto se ignora (el SDK solo espera objetos).
- `// DECISION`: un `index` de `tool_calls` negativo se trata como 0 para no perder la llamada.
