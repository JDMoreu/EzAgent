## Decisiones
- **`SwarmHost` + `HerdrHost`**: el Python recibe `herdr: Any` y llama métodos de `Herdr`, `AgentDriver` y `AgentSession` a la vez. En Rust esos tres son piezas distintas, así que el trait concentra las llamadas y `HerdrHost` las compone (`Herdr` + `AgentDriver<Arc<Herdr>>`). Las pruebas usan `FakeHost`.
- **`Book` compartido y `reset_launches` como `Arc<dyn Fn>`**: evita la auto-referencia de `reset_launches=self._reset_launches` en `Recovery` y comparte estado y despertador con el hilo de apertura.
- **`tick` devuelve `DbResult<bool>`**: en Python las excepciones salen del método y las atrapa el bucle; aquí el bucle registra el error con `tracing` y sigue, igual que el `except Exception` original.
- **`start(self: &Arc<Self>)` y `stop` sin plazo**: el hilo necesita un `Arc` para tickear; `stop` despierta el ciclo y espera la pasada en curso (en Python `join(timeout=5)`), que queda acotada por los timeouts de Herdr.
- **`BROADCAST` explícito en los `post`**: el Python omite `to` (valor por defecto `*`); `Db::post` de Rust no tiene valores por defecto y rechaza `""`.
- **`find_command_dir`**: `sys.executable` → `current_exe`; el resto (`.exe`/nombre junto al binario y PATH con PATHEXT) es el mismo.
- **Errores de la herramienta**: `SwarmError` conserva su texto; un fallo interno del tablero sale como «Error del enjambre: …» (el Python añade el nombre del tipo de excepción). Los ids de incidente se leen como dígitos ASCII; `str.isdigit()` de Python acepta además dígitos exóticos cuyo `int()` lanzaría `ValueError` (no reproducido; entrada irreal para el LLM).
- **`role_name` con `unwrap_or_default`**: la salida de `_slug` siempre es válida o vacía, así que no hay error alcanzable que ocultar.

## Pendiente o riesgos
- **`stop` sin plazo**: si una pasada está dentro de una llamada a Herdr, se espera a que termine (10–20 s como máximo por sus propios timeouts). Si la UI necesita un corte duro, haría falta un `JoinHandle` con watchdog o un flag dentro de las llamadas.
- **`HerdrHost` congela la configuración**: `AgentDriver::new` toma un clon de `VoiceConfig` (igual que F4-11); cambiar perfiles en caliente exige reconstruir el stack/driver.
- **Texto del fallo de apertura**: solo se conserva el mensaje de Herdr, no el tipo de excepción que Python incluiría en `str(exc)`; el resto del aviso es literal.
- **Dígitos exóticos en `incident`**: `isdigit()` de Python acepta superíndices que `int()` rechaza; aquí se tratan como «no es número» y se usa el incidente único. Entrada irreal para el LLM, anotada por si la paridad estricta la cubre.
- **Selección de la herramienta**: `build_swarm_tools` devuelve la herramienta cuando hay stack; el filtro por intención (`select_tool_names`) vive en otro módulo y no entra en este brief.
