## Notas específicas
- `store`, `service`, `view`, `protocol`, etc. (F3-11 y F3-12) ya están integrados: úsalos, no los toques. Lee sus informes en `rust-migration/reports/`.
- Seguridad (no negociable): el servidor **solo escucha en `127.0.0.1`** y exige el **token de sesión** en cada petición; sin token válido responde igual que el Python. Servidor HTTP con `tiny_http` (ya declarado), un hilo por petición o un pool pequeño, sin async.
- `cli.rs` es la lógica del comando `ezs` (argumentos, subcomandos, formato de salida); `bin/ezs.rs` solo llama a `cli`. Aquí **sí** se permite `println!` (solo en `cli.rs` y `bin/ezs.rs`). La salida de `ezs` debe ser idéntica byte a byte a la del Python (el oráculo `swarm.jsonl` tiene casos de `ezs`).
- Códigos de salida de `ezs` igual que el Python.
