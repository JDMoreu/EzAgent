## Notas específicas
- `ez-stt` ya tiene `casefold.rs` y `dictionary.rs` (F2-06): no los toques. `ez-core` está declarado como dependencia.
- Cliente HTTP de whisper.cpp con `reqwest::blocking` (multipart a mano si hace falta: `reqwest` no tiene la característica `multipart` activa; arma el cuerpo con el `boundary` en el código, igual que haría `httpx`). El servidor `whisper-server` es un proceso hijo: `std::process::Command` con argumentos en lista, entorno explícito y sin shell.
- La selección de motor (`auto` prefiere Vulkan y cae a CPU), rutas de binarios y modelos salen de `ez_core::downloads` / `ez_core::config::VoiceConfig`.
- Para las pruebas unitarias usa un servidor HTTP falso con `std::net::TcpListener` en un hilo.
